# Example portability policy

| Class | Examples | Treatment |
| --- | --- | --- |
| Portable | reviewed instructions, generic hooks, documented workflow policies | version after review |
| Machine-local | paths, editor preferences, OS integration, trusted-workspace state | configure locally; do not distribute |
| Sensitive | credentials, sessions, tokens, private keys, personal data | never version; rotate if exposed |

This is a classification example, not a restore procedure.
